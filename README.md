## 🌟 Overview
This repository hosts a fully functional, web-based Terminal Simulator serving as an interactive resume and portfolio. It simulates a raw Unix/Linux command-line environment tailored specifically to my background in **Electrical Engineering (Power Systems)**, **Deep Learning (PINNs)**, and **Software Architecture**.

### 🔥 Key Features
- **Authentic Terminal Engine**: Supports standard Linux commands (`help`, `clear`, `pwd`, `date`, `echo`, `ping`) and arguments.
- **Multilingual Support**: Switch seamlessly between Vietnamese (`vi`), English (`en`), and French (`fr`) using the `lang --[code]` command.
- **Interactive File System**: Features draggable, resizable windows acting as GUI overlays above the terminal.
- **Audio Feedback**: Custom Web Audio API integration for authentic retro "tick-tick" typing and output sounds.
- **Direct Communication**: Integrated `mailto` bridging and EmailJS form to establish a "Secure Uplink" directly to my inbox.

## 🛠️ Built With
- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables for CRT and Neon Glow effects
- **Animation**: Framer Motion (for smooth window dragging and maximizing)
- **Deployment**: Vercel

## 🚀 Local Development

To run this project locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ntthang-dev/ntthang-dev.github.io.git
   cd ntthang-dev.github.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🌐 Deployment (Vercel)
This portfolio is optimized for zero-config deployment on Vercel:
1. Push this repository to GitHub.
2. Log into [Vercel](https://vercel.com) and click **Add New Project**.
3. Import the repository from your GitHub account.
4. Leave the default settings (Framework Preset: **Vite**, Build Command: `npm run build`, Output Directory: `dist`).
5. Click **Deploy**.
